Starter HTML/CSS/JS project with asset folders (images & videos).

Files created:
- index.html
- css/style.css
- js/script.js
- assets/images/sample.svg (placeholder image)
- assets/videos/README.md (instructions for adding video files)

How to use:
1. Open index.html in your browser (or view it on GitHub Pages after enabling).
2. To add your own image, replace assets/images/sample.svg or add files to the folder and update the <img> src.
3. To add a video, upload assets/videos/sample.mp4 and it will be used by the page, or edit index.html to point to an external video URL.

Commands (local):
- git clone https://github.com/ashish1332005/New.git
- cd New
- Open index.html in browser or run a local server (e.g., `python -m http.server`).
